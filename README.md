# Theia (Тея)

> **Статус:** проектирование / specification-first. Это заготовка проекта, а не готовый VPN или прокси.

**Theia** — лёгкое клиент-серверное ядро на Rust с **одним бинарным файлом** для обеих ролей: сервера (управление inbound-подключениями) и клиента (подключение к ним). Оба режима используют TOML-конфигурацию и терминальный интерфейс на `ratatui`. Никакой базы данных, веб-панели или обязательных внешних сервисов.

## Цели

- **SmartTheia**: собственный *прикладной* протокол туннелирования поверх стандартных защищённых транспортов: HTTP/3 over QUIC (приоритет) и HTTP/2 over TLS (fallback).
- **QUIC/BBR**: BBR как целевой алгоритм управления перегрузкой, с проверкой поддержки конкретной версии библиотеки и измерениями.
- **Windows-клиент**: как минимум локальный HTTP CONNECT / SOCKS5 прокси и управление системными прокси-настройками с безопасным восстановлением.
- **Сервер**: настраиваемые inbound, статические пользователи/ключи, ограничения и диагностика без БД.
- **TUI**: две чётко разделённые области: «Для сервера» и «Для клиента».

## Принципы

Pragmatic engineering, KISS, DRY, SOLID, DDD (только полезные границы доменов), TDD, тесты прежде оптимизаций. Протокол нельзя считать невидимым для DPI без воспроизводимых измерений. Сходство с браузерным TLS ClientHello не означает неотличимость всего трафика.
